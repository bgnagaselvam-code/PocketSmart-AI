# PocketSmart AI – Project Description

## Problem
Students and young users often track income and expenses manually and may not know where their money is being spent.

## Solution
PocketSmart AI provides a dashboard where users enter monthly income and expenses. It calculates the balance, groups expenses by category, and produces practical budget recommendations. An optional Gemini API connection provides AI-generated suggestions.

## Technology
- Python
- FastAPI
- HTML/CSS/JavaScript
- Google Gemini API (optional)
- REST API

## Workflow
1. User enters monthly income.
2. User enters expenses and categories.
3. Frontend sends data to FastAPI.
4. Backend calculates totals and categories.
5. Recommendation engine provides advice.
6. Optional Gemini API generates additional recommendations.

## Expected outcome
A working web-based budgeting assistant with a clear UI, REST API, and optional generative-AI capability.
